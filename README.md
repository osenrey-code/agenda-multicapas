# Agenda Multicapas

Agenda web hecha con HTML, CSS y JavaScript. Muestra los contactos almacenados en la API indicada por la asignacion y permite registrar contactos nuevos con `fetch`.

## Requisitos cubiertos

- Listar todos los contactos guardados usando `GET`.
- Guardar nuevos contactos usando `POST`.
- Enviar el cuerpo JSON con los campos `nombre`, `apellido` y `telefono`.
- Mostrar mensajes de carga, exito y error.
- Validar que los campos no esten vacios antes de enviar.

## Ejecucion

Abre `index.html` en el navegador o levanta un servidor local desde esta carpeta:

```powershell
npx serve .
```

La URL usada por la aplicacion es:

```text
http://www.raydelto.org/agenda.php
```
